## 1. 書く内容

### A. 今あるページの書きかけ(公開に必須)

| ページ | 書くこと | 目安 |
|---|---|---|
| トップ(運営者の1行) | 作業療法士何年目か・どんな分野か・国試をどう乗り越えたか | 1〜2行 |
| 運営者情報 | ① OTを目指したきっかけ・学生時代 ② 今の分野(職場が特定されない書き方で) ③ このサイトを作った理由 ④ 連絡先(XのURL か Googleフォーム) | 各3〜5行 |
| 勉強スケジュール記事 | 受けた年と、始めたときの実力 / やってよかったこと3つ / 月ごとの表 / 時期ごとのくわしい話 / 直前期の1日 / 失敗したこと | 3,000〜5,000字 |
| 参考書レビュー記事 | 実際に使ったものだけ:名前・種類・評価・向いている人 / 1冊ずつ「よかった点・イマイチな点・使い方」/ タイプ別のおすすめ / アフィリエイトのリンク | 3,000〜5,000字 |
| プライバシーポリシー | 制定日 / アクセス解析を入れるならツール名 | 数行 |

書き方のコツ
- 「自分にしか書けないこと」(失敗・数字・写真)を多めに。読む人の信頼と、検索の評価の両方に効きます。
- 参考書は**本当に使ったものだけ**(ステマ規制)。書き込みやふせんの写真があると強いです。
- 職場・学校・患者さんが特定される情報は書かない。

## 2. SEO(検索対策)の方針

### 前提
- 「作業療法士 国家試験」まわりは、予備校・転職サイト・出版社が強い分野です。大きな言葉(「作業療法士 国家試験」)で上位を取るのは難しいので、**細かい言葉(ロングテール)をたくさん取る**作戦にします。
- 医療・資格の情報は、Googleが「誰が書いたか」「経験があるか」を重く見る分野です(E-E-A-T)。**現役OTの体験**と**出典**が武器になります。

### 優先順位つきのやること

| 優先 | やること | 効果 | 担当 |
|---|---|---|---|
| 1 | **独自ドメインを取る**(例: `nekodango-ot.com`、年1,500円前後) | GitHub Pages の `ユーザー名.github.io/リポジトリ名/` のままだと、`robots.txt` が効かず、サイトの評価も育てにくい。ASP審査でも有利 | あなた(購入)→ 私(設定) |
| 2 | **Google Search Console に登録**して、サイトマップを送る | 検索に載るまでが早くなり、どんな言葉で来ているかが見える | あなた(登録)→ 私(手順) |
| 3 | **1問1ページの解説ページを作る**(例: `/q/61A027.html`「第61回 作業療法士国家試験 午前27 解答・解説」) | 「第61回 午前27」「Dダイマー 国試」などの細かい検索から人が来る。いちばん大きな伸びしろ | 私 |
| 4 | **回ごとのまとめページ**(「第61回 問題・解答・解説一覧」+ 合格率・合格基準) | 「第61回 作業療法士 国家試験 解答」で探す人の入口になる | 私 |
| 5 | **体験談の記事を増やす**(下の候補) | 「勉強法」「参考書」で探す人を呼べる。アフィリエイトの売上に直結 | あなた(体験)→ 私(文章を整える) |
| 6 | 記事に構造化データ(Article・パンくず)を入れる | 検索結果での見え方が少しよくなる | 私 |
| 7 | X で「今日の1問」を毎日投稿 | サイトへの流入と、名前で検索してくれる人が増える | あなた |

### 1問1ページで気をつけること
- **解説のない問題のページは検索に出さない**(noindex)。問題を写しただけのページは「中身が薄い」と判断され、サイト全体の評価を下げます。
- 解説は、**内容を確認してから**検索に出す(未監修のまま大量に公開しない)。
- 各ページに厚生労働省の出典を書く(今のアプリと同じ)。

### 記事の候補(ねらう検索語)
| 記事 | ねらう検索語 |
|---|---|
| 国試はいつから勉強する?実習との両立 | 作業療法士 国試 いつから |
| 実地問題の解き方(症例の読み方) | 作業療法士 国試 実地問題 対策 |
| 専門基礎(解剖・生理・運動学)の覚え方 | 作業療法士 国試 解剖 覚え方 |
| 直前1か月にやったこと | 作業療法士 国試 直前 |
| 第61回を振り返って(難しかった問題) | 第61回 作業療法士 国家試験 難易度 |
| 合格率・合格基準の推移(厚労省の発表から) | 作業療法士 国家試験 合格率 |
| 落ちそうで不安なとき(メンタル) | 作業療法士 国試 不安 |

### やらないこと
- AIに丸投げした記事の大量投稿
- 過去問を写しただけのページを増やす
- 検索語の詰め込み、他サイトのコピー
