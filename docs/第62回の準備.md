## 合格発表のあと(3月下旬)
1. 厚労省の「第62回理学療法士国家試験及び第62回作業療法士国家試験の合格発表について」のページを開く
2. **作業療法士**の欄から、出願者数・受験者数・合格者数・合格率・新卒の数字、合格基準を `content/goukaku.json` の先頭に1行足す(`source` にそのページの URL)
3. `npm test`(合格率が人数から計算した値と合うかを確かめる)

## 問題を入れる手順(4月下旬〜)
1. 厚労省の「問題および正答について」のページから、作業療法士の PDF を保存する
   - `raw/mhlw/62/09a_01.pdf`(午前の問題)、`09a_02.pdf`(午前の別冊)、`09b_01.pdf`、`09b_02.pdf`、`09seitou.pdf`(正答)
2. `scripts/extract/pdf.mjs` に第62回を足す
   - `EXAMS` に `62`、`SOURCE_PAGES` に掲載ページの URL、`EXAM_YEAR` に `62: 2027`
3. `npm run data`(問題・正答・画像を作る)→ `check.mjs` の報告を見て、読めない文字などを直す
4. `scripts/extract/data.test.mjs` の「10回ぶん」のテストに 62 を足す → `npm test`
5. 採点除外・複数正解の問題は、厚労省の「採点除外等の取扱いをした問題」の PDF と照らし合わせる
6. `content/next-exam.json` を第63回の情報に書きかえる(なければ消す)
7. `ot-site/index.html` の「2,000問」「10年分」と、カウントダウンの日付・回を書きかえる。`src/logic/stats.ts` の `NEXT_EXAM` も
8. 解説を書く(`public/data/explanations/62.json`)→ `npm run review` で監修 → 公開

## 気をつけること
- 正答は**厚労省の発表どおり**。予備校の速報とちがっていたら、厚労省が正しい
- 問題文・図は厚労省の著作物(PDL1.0)。出典と「加工した旨」を必ず書く(解説ページには自動で入る)
- 別冊の写真に、国以外の権利(出版社の図など)がふくまれていないか気になるときは、厚労省 医政局 医事課 試験免許室に確認する
