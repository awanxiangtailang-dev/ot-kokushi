# 公開の手順(独自ドメイン + GitHub Pages)

ドメインは Cloudflare で買う。サイトは GitHub Pages に置く(無料)。

## 1. ドメインを買ったら(1か所だけ書きかえる)

`site.config.json` の `siteUrl` に、買ったドメインを書く。

```json
{ "siteUrl": "https://買ったドメイン.com" }
```

これで、ページの URL・サイトマップ・robots.txt・CNAME がぜんぶこのドメインになる。(設定済み: `https://ot-kokushi.com`)

書きかけの記事は `drafts` に入れておくと、公開版に入らず、トップ・アプリ・解説ページからのリンクも消える。
書き終えたら `drafts` から外せば、次の公開で出る。

## 2. GitHub に上げる

1. GitHub のアカウントを作る(本人が行う)
2. 新しいリポジトリを作る(名前の例: `ot-kokushi-note`、Public)
3. このフォルダを push する(Claude が行う)
4. リポジトリの Settings → Pages → Source を「GitHub Actions」にする

push すると `.github/workflows/deploy.yml` が動いて、テスト → 公開用フォルダづくり → 公開まで自動で進む。
記事の書きかけが残っていると、公開の手前で止まる(書きかけのまま公開されないように)。

## 3. ドメインと GitHub Pages をつなぐ(Cloudflare の DNS)

Cloudflare の管理画面 → 買ったドメイン → **DNS** → **Records** → **Add record** で、次を足す。

| Type | Name | 内容(IPv4 / IPv6 / Target) | Proxy status |
|---|---|---|---|
| A | `@` | `185.199.108.153` | DNS only(灰色の雲) |
| A | `@` | `185.199.109.153` | DNS only |
| A | `@` | `185.199.110.153` | DNS only |
| A | `@` | `185.199.111.153` | DNS only |
| AAAA | `@` | `2606:50c0:8000::153` | DNS only |
| AAAA | `@` | `2606:50c0:8001::153` | DNS only |
| AAAA | `@` | `2606:50c0:8002::153` | DNS only |
| AAAA | `@` | `2606:50c0:8003::153` | DNS only |
| CNAME | `www` | `<GitHubのユーザー名>.github.io` | DNS only |

- **Proxy status は「DNS only」(灰色の雲)にする。** オレンジの雲のままだと、GitHub が HTTPS の証明書を作れないことがある
- 値は GitHub の公式ドキュメント「Managing a custom domain for your GitHub Pages site」で最新のものを確認する

## 4. GitHub 側の設定

1. リポジトリの Settings → Pages → **Custom domain** に、買ったドメインを入れて Save
2. 数分〜1日で「DNS check successful」になる
3. **Enforce HTTPS** にチェックを入れる(証明書ができるまで押せないことがある)
4. (おすすめ)アカウントの Settings → Pages → **Add a domain** でドメインを「確認済み」にする。ほかの人に乗っ取られるのを防げる(TXT レコードを1つ足す)

## 5. 公開したあと

- Google Search Console にドメインを登録して、`https://買ったドメイン.com/sitemap.xml` を送る
- 監修済みの解説ページだけがサイトマップに入る(未監修は noindex)
