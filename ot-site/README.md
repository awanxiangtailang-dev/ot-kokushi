# OT国試ノート：使い方

作業療法士の国家試験の勉強法を体験談で紹介する、アフィリエイト用のサイトです。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | トップページ（記事一覧・運営者紹介） |
| `articles/schedule.html` | 体験談記事：勉強スケジュール |
| `articles/textbooks.html` | 体験談記事：使った参考書レビュー（アフィリエイトのメイン） |
| `about.html` | 運営者情報 |
| `privacy.html` | プライバシーポリシー・免責事項・広告表示 |
| `style.css` | デザイン |

## やること

1. **オレンジの点線の枠（✏️ 自分で書く）を、自分の体験に書きかえる。** 書き終わったら `<div class="todo">…</div>` ごと消す。
2. **【　】の部分を埋める。**（ニックネーム、日付、参考書の名前など）
3. **アフィリエイトのリンクを入れる。** `href="#"` の部分を、Amazonアソシエイトや楽天アフィリエイトで作ったリンクに置きかえる。
4. **公開する。**（下を参照）

## 守ること

- 「PR」の表示は消さない（ステマ規制）。
- Amazonの定型文（フッターの「Amazonのアソシエイトとして…」）は消さない。
- 実際に使っていない商品を、使ったように書かない。
- Xの有料広告で、Amazonのリンクを宣伝しない（報酬の対象外になる）。

## 公開のしかた（無料）

- **Netlify Drop**（いちばん簡単）：https://app.netlify.com/drop を開いて、`ot-site` フォルダをドラッグ＆ドロップするだけで公開できます（アカウント登録が必要）。
- **GitHub Pages**：GitHubにこのフォルダをアップして、Settings → Pages で公開します。
- **独自ドメイン**：年1,000〜2,000円くらいで取れます。ASPの審査やSEOのためには、あったほうが有利です。

## 公開したあと

1. 楽天アフィリエイトに登録（審査なし）→ すぐリンクを貼れます。
2. A8.net、もしもアフィリエイトに登録して、「通信講座」「国家試験」で案件を探します。
3. Amazonアソシエイトは、記事がいくつかたまってから申しこみます（登録から180日以内に3件の売上が必要）。
4. Xで勉強のコツを投稿して、記事へ誘導します。
